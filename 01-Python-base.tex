\section{Основы Python — типы, управление, функции}
\subsection*{Синопсис:}

\paragraph*{Цель:}

базовый синтаксис, типы, управление потоком.

\paragraph*{Длительность:}
 1–2 недели.

\paragraph*{Теория(минимум):}

\begin{itemize}
\item Динамическая типизация, \texttt{ type(), isinstance()}.
\item Числа: \texttt{int} (произвольная точность), \texttt{float, complex, Decimal}.
\item Строки: \texttt{str, f-strings}, методы (\texttt{split, join, strip, replace, startswith, endswith}).
\item Логический тип, \texttt{None, truthy/falsy}.
\item Управление: \texttt{if/elif/else, match/case (3.10+), for, while, break, continue, else} у циклов.
\item Функции: \texttt{def}, параметры (позиционные, именованные, \texttt{*args, **kwargs, default}), \texttt{return, None}.
\item Область видимости: \texttt{LEGB, global, nonlocal}.
\item Comprehensions: \texttt{list, dict, set, generator}.
\item Аннотации типов: \texttt{def f(x: int) -> str:}
\end{itemize}
